Codex Pulse · Windows 免安装版

1. 完整解压 ZIP，双击 CodexSpeedPanel.exe。
2. 程序检查候选数据目录并打开网页。从顶部菜单选择要查看的聊天。
3. 找不到数据时，展开“数据目录”，手动填写 Codex 数据文件夹或点击“重新检测”。
4. 用完点击“关闭监测”，或运行“关闭监测.cmd”。关闭网页不会自动退出后台。

“最近一条消息”：最近发出的消息，以及处理它时的全部模型调用。
“整个聊天”：所选聊天从开始到现在的累计消耗。
明细可按消息汇总，也可查看模型调用。点击箭头查看输入、缓存、输出和思考。
缓存输入包含在输入中，思考输出包含在输出中；合计为输入加输出。
k 表示千，M 表示百万；悬停数字可看完整值。

网页每 3 秒刷新，隐藏时不再发起读取。数据未变化时复用统计结果。
本版本不扫描 Codex 窗口、不启动无障碍扫描进程。
Windows 包不需要 Python、管理员权限或 API Key。
电脑需要已经安装并使用过 Codex，且本地日志格式受支持。

在 Codex 侧栏查看：打开 http://127.0.0.1:19876/。
真实聊天名称、用量和目录属于本地信息，分享截图前请检查。
